# Greenden - Plant Store Web Application 🌿

Greenden is a responsive e-commerce web application designed for a plant store, offering a wide range of artificial and natural flowers and indoor plants[cite: 2].

## 🚀 Features
* **Responsive Design:** Fully optimized for mobile devices and desktops using Tailwind CSS.
* **Multi-page Layout:** Includes a Home page[cite: 2], a Product catalog page[cite: 3], and an interactive Contact page[cite: 1].
* **Interactive UI Elements:** Responsive navigation bars, hover effects, product grid layouts, and clean subscription forms.

## 🛠️ Technologies Used
* **HTML5**
* **Tailwind CSS**

## 📂 Project Structure
* `index.html` - The landing page featuring best sellers, customer reviews, and about section[cite: 2].
* `product.html` - The product showcase page with a search bar and plant catalog[cite: 3].
* `contact.html` - The customer contact form page[cite: 1].
* `src/output.css` - Compiled Tailwind CSS stylesheet.
* `images/` - Directory containing asset images for plants and headers.
